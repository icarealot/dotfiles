# Git

| File                 | Description                                 |
|----------------------|---------------------------------------------|
| .gitconfig           | Git aliases for everyday operations.        |
| .gitignore-unity     | .gitignore template for Unity projects.     |
| .gitattributes-unity | .gitattributes template for Unity projects. |

## Prerequisites

[Git](https://git-scm.com/)

## Install

### .gitconfig

Append it to `~/.gitconfig`.

### .gitignore-unity & .gitattributes-unity

- Remove the suffix `-unity`.
- Copy them to the Unity project folder.
