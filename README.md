# dotfiles

Personal configs, tools, and AI agent setup.

| Folder | Description |
|---|---|
| [`ai/claude`](ai/claude) | Claude Code global settings: custom status line, advisor model, and a Stop hook for native notifications |
| [`ai/instructions`](ai/instructions) | Reusable AI agent instructions (global tone/style, Unity project conventions) |
| [`ai/pi`](ai/pi) | Pi coding agent extensions |
| [`ai/skills`](ai/skills) | Reusable agent workflows for discussion, domain modeling, Unity specs and tasks, TDD, implementation, code review, commits, build notes, and library docs |
| [`g-helper`](g-helper) | G-Helper config for ROG Zephyrus G14 — power limits, fan curves, 80% battery cap |
| [`git`](git) | Git config with a `dog` alias for a compact, decorated log graph |
| [`husky.NET`](husky.NET) | Husky.Net pre-commit hook for Unity C# — runs `dotnet format` on staged `.cs` files |
