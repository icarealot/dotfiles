# Firefox

| File             | Description                            |
|------------------|----------------------------------------|
| `userChrome.css` | Custom css and settings                |

## Prerequisites

[Firefox](https://www.firefox.com/)

## Install

- `about:config` -> enable `toolkit.legacyUserProfileCustomizations.stylesheets`
- `about:support` -> open `Profile Folder`
- Copy `userChome.css` to `Profile Folder\chrome\`
- Restart Firefox

## Settings

### Disable close windows when close last tab

`about:config` -> disable `browser.tabs.closeWindowWithLastTab`
