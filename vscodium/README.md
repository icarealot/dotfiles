# VSCodium

| File            | Description                            |
|-----------------|----------------------------------------|
| `settings.json` | Custom settings                        |

## Prerequisites

[VSCodium](https://vscodium.com/)

## Install

Copy `settings.json` to

- **Windows:** %APPDATA%\Code\User\settings.json
- **macOS:** $HOME/Library/Application\ Support/Code/User/settings.json
